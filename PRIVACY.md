# Privacy Policy

**Dynamic Pricing**  
Last Updated: December 2, 2025

## Overview

Dynamic Pricing ("we", "our") is a SaaS platform that provides pricing optimization recommendations for e-commerce merchants. This privacy policy explains how we collect, use, and protect data.

## Data We Collect

### From Our Customers (Merchants)
- Account information (email, business name)
- E-commerce store data (product catalogs, pricing) via authorized OAuth connections
- Usage data related to our platform

### From Public Social Media Sources
- We collect publicly available posts and comments from social media platforms (including Reddit) related to product categories
- We analyze this content for aggregate sentiment scoring only
- We do **NOT** collect, store, or track individual user profiles, usernames, or personal information

## How We Use Data

### Social Media Data (Including Reddit)
- Content is processed in real-time to extract sentiment scores (positive/negative/neutral)
- Raw content is processed immediately and discarded
- Only aggregate sentiment metrics are retained (e.g., "Product category X has 72% positive sentiment this week")
- We do **NOT** store original post/comment text
- We do **NOT** track or identify individual social media users
- We do **NOT** use social media data for AI/ML model training
- We do **NOT** resell or redistribute social media data

### Merchant Data
- Used solely to provide pricing recommendations
- Shared only with authorized e-commerce platforms (Shopify, WooCommerce) to apply price updates with merchant approval
- Never sold to third parties

## Data Retention

| Data Type | Retention Period |
|-----------|------------------|
| Raw social media content | Not retained (processed and discarded immediately) |
| Aggregate sentiment scores | 90 days |
| Merchant account data | Duration of account + 30 days |
| Pricing history | 1 year |

## Data Deletion
- When social media users delete their content, we have no retained copy to remove (raw content is never stored)
- Merchants may request full data deletion by contacting us
- We comply with deletion requests within 30 days

## Third-Party Services

We integrate with:
- **Shopify / WooCommerce** - E-commerce platforms (via authorized OAuth)
- **Reddit API** - Public content for sentiment analysis (read-only, aggregate analysis)
- **OpenAI** - Sentiment analysis processing (no user data shared, only anonymized text snippets)

## Security
- All data transmitted via HTTPS/TLS encryption
- Database access restricted and encrypted
- OAuth tokens stored securely and never exposed

## Your Rights

You have the right to:
- Access your data
- Request correction of inaccurate data
- Request deletion of your data
- Withdraw consent for data processing
